FieldCraft – external NGSolve runtime

The desktop application runs this solver in a separate Python process. Its numerical and CAD dependencies are installed in that interpreter. The FieldCraft application has its own distribution notices.

Package contents and matching sources

The R5 network installers for macOS, Windows, and Linux download the original runtime archives from their publishers during setup. Each installer records the download URLs and SHA-256 digests in runtime.lock (macOS) or runtime-lock.json (Windows and Linux). Windows on Arm uses x64 emulation for the solver wheels. The optional offline packages include their runtime archives or an installed private runtime.

Redistributing an offline installer

LGPL 2.1 §4 covers distribution of the library in binary form. For a downloadable release, provide equivalent access from the same place to its complete corresponding machine-readable source, including the material required to build and install the library. Preserve the applicable copyright notices and licence texts for each component.

The NGSolve, netgen-mesher, netgen-occt and ngsolve-openblas releases listed above publish only wheels on PyPI. The source references identify upstream versions. Matching all wheel producers' patches, submodules, build inputs and bundled runtime libraries to the actual binaries and supplying the corresponding source remain release-publisher work for an offline redistribution. This notice may accompany the release alongside the source material.
